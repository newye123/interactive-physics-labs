# interactive-physics-labs

[![tests](https://github.com/newye123/interactive-physics-labs/actions/workflows/ci.yml/badge.svg)](https://github.com/newye123/interactive-physics-labs/actions/workflows/ci.yml)
[![license: NC-1.0](https://img.shields.io/badge/license-NC--1.0-orange.svg)](LICENSE)

**高中「电路及其应用」一章的交互式课堂包：电路求解器 + 电表读数训练器 + 分镜脚本。零依赖，纯静态，双击就能开。**

不是课件，不是 PPT。是**可以拖、可以接、可以读数**的仿真台：
学生自己搭电路、合闸、看表针偏转；读数训练器让他们拖游标尺和鼓轮，练到不会看错。

```bash
git clone https://github.com/newye123/interactive-physics-labs.git
cd interactive-physics-labs
npm test        # 4 组自检，零依赖
npm run serve   # http://127.0.0.1:5173
```

---

## 里面有什么

| 目录 | 内容 | 体量 |
|---|---|---|
| `labs/circuit/` | 电路工作台：求解器（113 行）+ 模型（169）+ 渲染（306）+ 应用（422）+ 7 个预设电路 | ~1,100 行 |
| `labs/m6/` | 电表读数训练器：游标卡尺 + 螺旋测微器，含放大镜窗口 | ~690 行 |
| `labs/stage/` | 分镜脚本引擎：把一节课拆成固定七拍，台词外置可改 | ~620 行 |
| `docs/` | 两份方案：故事化互动的调研与对抗审查、第十一章大屏课堂包设计 | — |

七个预设电路：`blank` / `series` / `parallel` / `ohm` / `emf` / `loading` / `short`。
最后一个 `short`（短路）是故意留的——**让学生看见电流表指针打到底**，比讲十遍"不许短路"有用。

## 它到底在解决什么

这一章有三个地方，讲台上讲不清、黑板上画不出：

1. **「电子走一米要几小时，为什么一按开关灯就亮？」**
   学生脑子里的模型是"电子跑得快"。真相是电场以光速建立、电子漂移极慢。
   双轨动画能同时显示两个速度，比任何比喻都直接。

2. **「并联一个电阻，总电阻为什么变小？」**
   直觉是"加东西应该变大"。拖动台让他们自己发现：并联后的总电阻比最小的那个还小。

3. **「读数为什么总是差半格？」**
   螺旋测微器的半刻度线露不露，是纯视觉判断。静态图看不出，得能拖。

## 一个真实的 bug：一行相对路径，一块白屏

这个仓库不是直接搬过来的。搬完之后我加了一个断链检查，第一次跑就红了：

```bash
$ node tests/check_assets.mjs
断链  labs\circuit\workbench.html  ->  ../index.html
扫描 3 个页面，检查 16 条本地引用，断链 1 条
rc=1
```

`workbench.html` 在 `labs/circuit/` 下，`../index.html` 指向 `labs/index.html`——
**这个文件不存在**。那个「回目录」按钮，从做出来那天起就是坏的。

修法是少一个点：

```diff
-    <a class="tb-btn" href="../index.html">回目录</a>
+    <a class="tb-btn" href="../../index.html">回目录</a>
```

修完：

```bash
$ node tests/check_assets.mjs
扫描 3 个页面，检查 16 条本地引用，断链 0 条
rc=0
```

### 为什么这个 bug 值得单独写一段

因为它**不会报错**。

纯静态站点没有构建步骤，没有打包器帮你解析路径。写错的相对路径不会在控制台留一行红字，
它只会在你点下去的时候变成一块白屏。而白屏和"代码有 bug"在讲台上看起来一模一样——
老师分不清，学生更分不清。

更麻烦的是：**这个链接在开发时永远点不到。** 你在 `index.html` 里点进去，一路正常；
只有从工作台往回点，才会踩到。少有人走的那条路，就是坏的。

所以判据不是"我看过页面能开"，是**"每一条引用都解析过"**。
这就是 `tests/check_assets.mjs` 存在的理由：扫描全部 HTML，逐条解析 `src` / `href`，一条不通就红。

## 第二个 bug：本地全绿，CI 全红

加完 `package.json` 之后，本地跑了一遍，四组检查全过：

```
✓ 电路求解器自检  (rc=0)  结果：17 通过，0 失败
...
4 通过 / 0 失败
```

推上去，CI 四路（node20/22 × ubuntu/windows）**全红**，而且红在同一步：

```
✗ node20 / ubuntu-latest   自检（基线必须绿）  failure
✗ node20 / windows-latest  自检（基线必须绿）  failure
✗ node22 / ubuntu-latest   自检（基线必须绿）  failure
✗ node22 / windows-latest  自检（基线必须绿）  failure
```

本地重跑，**也红了**：

```
FAIL rc=1      电路求解器自检
FAIL rc=1      电路模型自检
FAIL rc=1      读数训练器自检
PASS           静态资源断链检查
1 通过 / 3 失败
```

### 根因

`package.json` 里我写了 `"type": "module"`。这一行的意思是"本项目所有 `.js` 按 ES 模块处理"。
而那三个自检脚本用的是 `const S = require('./solver.js')`——**CommonJS 语法**。

在 ESM 作用域里，`require` 不存在。三个脚本同时挂掉。

### 为什么本地会绿过一次

因为**我是在加 `"type": "module"` 之前跑的那一遍**，加完没有再跑。

那行配置是后来补的（为了让 `tests/*.mjs` 有个正经的入口声明），补完直接提交了。
README 里那句「4 通过 / 0 失败」是从上一次的输出里抄的。

**这就是"改完没复跑"。** 一个改动只有一行，看起来不可能影响任何东西，于是没跑。

### 修法

删掉 `"type": "module"`。`tests/` 下的 `.mjs` 按扩展名已经是 ES 模块，不需要这行；
三个自检脚本按默认的 CommonJS 处理，`require` 正常工作。

```diff
-  "type": "module",
```

改完本地四绿，CI 四路也四绿。

### 教训

**改完必须复跑，尤其是"看起来不可能有影响"的改动。**

一行配置的杀伤力和一千行代码一样大——区别在于，一千行代码你会去跑一遍，
一行配置你会觉得"这能有啥影响"。

CI 在这里的唯一作用就是：**它不知道你本地跑过什么，它只认提交上去的东西。**
本地绿而 CI 红，说明本地那份绿不是真的。

## 自检

```bash
$ npm test
✓ 电路求解器自检  (rc=0)  结果：17 通过，0 失败
✓ 电路模型自检    (rc=0)  结果：17 通过，0 失败
✓ 读数训练器自检  (rc=0)  选项自检 PASS（100 例 × 3 题型）
✓ 静态资源断链检查 (rc=0)  扫描 3 个页面，检查 16 条本地引用，断链 0 条

4 通过 / 0 失败
```

四组检查，各有各守的东西：

| 检查 | 守什么 |
|---|---|
| 电路求解器自检（17 条） | 基尔霍夫方程解出来的数对不对。含「负载效应」一条：理想 5.0000 V vs 真实 0.2830 V——**电压表内阻会吃掉读数**，这个差必须算对，否则读数训练器教的就是错的 |
| 电路模型自检（17 条） | 元件增删改后，拓扑与方程同步更新 |
| 读数训练器自检 | 随机出 100 例 × 3 种题型，选项必须唯一正确；并核对教材例（卡尺 23.7 mm、千分尺 6.725 mm） |
| 断链检查 | 每一条本地引用都能解析 |

### 退出码三档

`0` 全过 / `1` 有失败 / `2` 跑不起来。

第三档是刻意的：`check_assets.mjs` 在**一条引用都没解析到**时返回 `2`，不是 `0`。
因为「扫了 3 个页面，0 条引用，0 条断链」和「全部通过」长得一模一样，
但前者意味着**探针失灵了**（目录扫错、正则挂了），不是站点健康。

负控实测过两条：

| 负控 | 注入 | 结果 |
|---|---|---|
| 1 | 把 `src="solver.js"` 改成 `solver2.js` | `rc=1`，报 1 条断链 |
| 2 | 把三个页面换成没有任何引用的空壳 | `rc=2`，报「一条引用都没解析到 —— 这是探针失灵」 |

## 教材版权边界（重要）

**本仓库不包含任何教材原文。**

- 设计文档里出现的是**页码与题号**（如「练习 3（p56）」），不是题目内容——指向不是复制。
- 开发时用过一份 OCR 出来的教材文本作为对齐参考，**那份文件不进仓库**，也不随任何分发物出去。
  教材版权归原出版方（人民教育出版社）所有。
- 代码、仿真模型、界面、分镜脚本都是自研的，与教材出版方无关。

如果你要基于本仓库做自己的课堂包，请自备教材，不要把我这份当成"教材电子版"的替代。

## 它明确不做什么

- **不做成通用物理引擎。** 只覆盖这一章的直流电路与电表读数。加交流、加磁场会让它变成一个半成品框架。
- **不追求仿真逼真度。** 差异化不在"像真的"，在"猜错 → 揭晓"这个认知落差。
- **没有课堂实测数据。** `docs/` 里写的「正确率 +10~15 个百分点」是**达标线（目标值）**，不是测出来的结果。
  目前没有做过对照班测试，所以任何"提升了多少"的说法都还没有证据。这一条必须说清楚，
  否则它就从"一个课堂包"变成了"一个宣称有效但没测过的课堂包"。
- **不是给学生的自学产品。** 它假设有一个老师在场，负责组织"先猜后揭晓"的动作。
