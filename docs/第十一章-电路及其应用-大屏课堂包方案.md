# 第十一章「电路及其应用」大屏课堂包 — 方案与对抗审查

> 版本 v0.1（草案）· 2026-10-18 · 状态：待「第 0 步试点课」验证后转 v1
>
> 教材：人教版《普通高中教科书·物理必修第三册》第十一章（教材 p52–p77；PDF 页码 = 教材页码 + 5，对应 PDF 第 57–82 页）

**设计坐标（已确认）**：只有教师大屏 · 常态课为主 · 先方案后开工。

结论先行，五条原则贯穿全部设计：

1. **不搬教材，搬冲突。** 每个模块先让学生猜错，再揭晓。兴趣不来自动效，来自"啊，我猜错了"。
2. **屏幕当裁判，不当演员。** 交互最终服务于全班动作（举手、喊数、上台），屏幕只提供证据。
3. **每个"好玩"都要落到教材某一页某一题**，否则砍掉。
4. **学 wedulab 的形态，不抄它的内容。**
5. **先上一节课，再写第一行代码。**

## 一、需求淬炼

**核心任务（写死）**：物理老师在一节 40 分钟常态课里，用大屏完成 **3 次「全班预测 → 揭晓 → 落题」** 循环。

**用户**：
- 主用户是老师。课前 5 分钟选模块，课上站在大屏前操作。设备：教室 Windows 电脑 + 投影/希沃一体机，可能配翻页笔。情绪：时间紧、怕翻车、要进度。
- 全班 45–55 人，坐在 4–9 米外看屏，不操作设备。情绪：容易走神，但对"猜"有参与欲。

**成功标准（可验收）**：
1. 上手：打开到第一个模块开始 ≤ 3 次点击，全程不需要鼠标精确操作。
2. 备课：每节课只挑 3 个模块，备课 ≤ 10 分钟（每模块自带 30 秒台本）。
3. 参与：每个模块内至少 1 次全班动作，老师能在 5 秒内判断多数派。
4. 效果：章末用教材「复习与提高」A/B 组做前后测，达标线定 **正确率 +10~15 个百分点**，并逐题看错误类型是否减少。
5. 留存（一票否决项）：两周内老师自愿、无人提醒地再次打开。做不到，项目停。

## 二、内容解剖：迷思地图 → 13 个模块

教材里藏着极好的"猜错素材"，很多是教材自己写的（比如 p55 说电子走 1 米要几个小时，又和"一按开关就亮"矛盾）。把每节的"坎"拎出来，一个坎配一个模块，出口题全部绑定教材原题：

| 模块 | 教材落点 | 一句话玩法 | 出口题（教材页） |
|---|---|---|---|
| M1 开灯一瞬间 | 11.1 p55 微观解释段 | 全班先猜"电子从开关到灯泡要多久"，然后双轨动画：电子漂移像蜗牛（10⁻⁴ m/s），电场以光速接通。揭晓：亮灯不是电子跑到了，是电场到齐了 | 自编估算题 + 练习 1（p56） |
| M2 电流不消失 | 11.1 p54 恒定电流 | 灯泡前后两个截面同时"数电子"，数量一样 → 电流处处相等；接 I=neSv 滑杆台（预设铜/盐水/二极管），拖 n、S、v 看电流表 | 练习 3（p56，4000 mA·h 估电流） |
| M3 R 到底听谁的 | 11.2 p57 U-I 图 | 拖电压，U 和 I 一起变，但屏幕上 U/I 的比值数字纹丝不动；换导体比值才变。"R 只跟导体有关"这句话让学生自己喊出来 | 练习 1（p61，四点比电阻） |
| M4 拉丝机 | 11.2 p58 定量关系 | 把导线均匀拉长：长度条变长的同时截面变细，R 按平方-平方关系跳涨；现场算教材盐水柱 30→40 cm 原题 | 练习 5、6（p61，盐水柱、长方体两方向） |
| M5 加热灯丝 | 11.2 p59 演示 | 复刻教材演示（酒精灯加热灯丝、灯泡变暗），ρ-T 曲线切换金属/锰铜/半导体；彩蛋：温度拉到底 R 变 0，电流永远转圈（超导） | 灯泡冷热电阻变式、练习 4（p61，鸟） |
| M6 读数训练器 | 11.3 p62–65 | 拖动游标尺/鼓轮摆位置，大屏出三种题：摆位、读数、找茬（挑一个故意错的读数）；覆盖 10/20/50 分度 + 螺旋测微器半刻度陷阱 | 练习 1、3（p67） |
| M7 谁在骗我 | 11.3 p65 + 11.4 练习 3（p71） | 教材原数据 87.4 Ω / 电压表 1 kΩ / 电流表 0.1 Ω，切内接外接，屏幕上三条数据：真实值、测量值、差值从哪来（电压表"偷"的电流用粒子显示） | 11.3 练习 3（p67）、复习 B 组 2（p76） |
| M8 分蛋糕 | 11.4 p68–70 | 串并联规律拖动台。反直觉点：并联一个电阻，总电阻比最小的那个还小——先猜再拖 | 练习 1、2（p71）、复习 A 组 4（p75） |
| M9 表头改造间 | 11.4 p70 例题 | 全章最燃：Rg=30 Ω、Ig=1 mA 的真表头摆中间，选串/并联、拖电阻，调对了指针满偏压线；调错了指针爆表（安全地炸）。教材例题、双量程练习现场做 | 练习 4、5（p71）、复习 B 组 5（p77） |
| M10 欧姆表照 X 光 | 11.5 p72 | 剖开欧姆表：表头 + 电池 + 调零电阻，拖 Rx 看指针，用"读数误差带"解释为什么指针在中间区域最准；换挡时内部电阻怎么变；红黑笔与内部电池极性的反直觉点 | 练习 2、3（p74） |
| M11 规范操作闯关 | 11.5 p73 | 对话框式操作序列（调零→选挡→短接→欧姆调零→测→×倍率→OFF），故意做错有后果：带电测电阻冒火花告警、换挡不调零读数漂、用完不放 OFF 提示漏液风险 | 练习 1、4（p74） |
| M12 黑箱侦探 | 复习与提高 B 组 4（p77） | 三接线柱黑箱，给出 1 Ω / 1.5 Ω / 2.5 Ω 的测量值，抽学生上台画内部四个相同电阻的接法，大屏核对 | 复习 B 组 4（p77） |
| M13 故障排查现场 | 11.5 练习 5（p74）+ 复习 B 组 6、7（p77） | 灯泡不亮、断导线，用电压挡沿路逐点探，读数推理故障位置；把讲义题变成侦探关卡 | 练习 5（p74）、复习 B 组 6、7（p77） |

每个模块内置**三档深度**：30 秒快演 / 3 分钟标准 / 8 分钟探究。赶进度用快演，公开课用探究。默认标准档。

## 三、信息架构

一个本地文件夹的静态站点，三类页面，就这么多：

1. **目录页**（唯一入口）：5 张节卡 + 章末 2 张。卡片上直接列模块，点一下进"今日队列"。
2. **今日队列**：老师课前把今天要用的 3 个模块点进来，上课按空格依次走，用完全部自动停止。为什么不是按章节浏览的多层导航：常态课的行动单位是"这节课用哪几个"，队列比目录树更贴任务。
3. **模块页**：每模块一个独立 HTML，全屏运行。**为什么模块独立成页**：一个模块改坏了不影响别的；单文件坏了单独重下。
4. **台本抽屉**（每模块内嵌，不是页面）：5 行脚本——说什么、问什么、点哪里、揭晓句、落点题。老师 30 秒扫完。

**关键路径**：双击 index.html → 点 3 个模块 → 按空格开始 → 每个模块三步（情境 → 预测 → 揭晓+落题）→ 自动回队列指向下一个。

**键盘映射**（配翻页笔用，全部单键）：空格 = 下一步；← → = 上/下个模块；F = 全屏；R = 复位到初始状态；1/2/3 = 选择预测选项。

**11.4 的一节 40 分钟样例**：
- 0–2′ 情境：一块 1 mA 的表头摆在屏中央——"它能直接测 0.6 A 吗？"
- 2–10′ M8 分蛋糕：两次全班口令（并联后总电阻变大还是变小？先猜后拖）
- 10–15′ 讲台推导：老师用屏上实时数字写 R=R₁+R₂（屏幕只出数字，公式靠板书）
- 15–32′ M9 表头改造间：全班喊"多一点/少一点"命中满偏；然后学生上台挑战双量程（练习 4）
- 32–38′ 落题：练习 3（87.4 Ω 内外接），做完对答案
- 38–40′ 布置真表实验：课后测灯泡冷热电阻

**状态处理**：
- 无加载态：本地文件双击即开，用系统字体，不闪不转圈。
- 空态：队列为空时提示"挑 3 个模块，一节课正好"。
- 错误态：短路时画布红闪一次 + 一行字"短路：电流抄了近道，谁被绕过了？"，不弹窗、不打断节奏。
- 降级态：老机器开"安全模式"（关粒子、关过渡，只留数据和指针）。
- 误触恢复：任何状态按 R 复位；队列存本地，不因误触丢失。

## 五、设计系统

投影环境是硬约束：灯亮着、屏幕反光、后排 9 米、手指粗。一切为"看得清、够得着"让路。

**颜色（一色一义，全章统一）：**
- 纸色底 `#F7F5F0`：亮环境光下不刺眼；不用纯白（反光）不用深色（一开灯就废）
- 主墨 `#23272E`：不用纯黑，大屏上纯黑和纸色对比过猛，久看发晕
- 操作蓝 `#1F5BD8`：按钮、焦点、强调
- 电流橙 `#E8590C`：**专用于电流粒子和导线**——学生三天后看到这个橙就知道"电在走"
- 电压青 `#0E7C86`：电压数字、电压表读数
- 表盘 `#1C1C1C` + 指针红 `#C92A2A`：跟随真表（真表针就是红的），仿仪器的地方不许花哨
- 通过绿 `#2F9E44` / 警示红 `#E03131`：只用于判分和错误后果，不作装饰
- 全部文字对比度 ≥ 4.5:1

**字体（零依赖：教室电脑不能指望联网）：**
- 中文：`"Source Han Sans SC", "Microsoft YaHei UI"`（雅黑是 Windows 教室机自带，保底绝不缺字）
- 数字/读数：`Consolas`（等宽，表盘数字不跳动）

**字号阶梯（1080p，后排 9 米可读，每一级都有理由）：**
- 情景问题/预测题：`44px`——全场核心，必须最大
- 结论句：`36px`
- 正文/台本：`28px`——小于 28px 不许上屏
- 关键读数：`72px` 起，且**一个屏幕同时最多一个**，出现第二个就失去焦点
- 验收办法：坐最后一排念得出来才算过

**间距/圆角/动效：**
- 8px 基准刻度（8/16/24/40/64）；可点元素 ≥ 64×64px
- 卡片圆角 12px，仪器 4px（仪器要像仪器）
- 过渡 ≤ 200ms；**电流粒子是唯一持续动画**，其余动画只在回答"为什么"时出现，讲完立刻静止
- 阴影最多一层或不用（投影下阴影是糊的）

**组件清单：** 大按钮（角上标快捷键）、预测闸门、写实指针表盘（Canvas 绘制）、旋钮/滑杆（可拖可点，点一下 ±1 格）、实时数据表、8 分钟计时条（不响铃）、台本抽屉。

## 六、技术决定

- **技术栈**：原生 HTML/CSS/JS + Canvas，无框架、无构建、无服务端。理由：教室电脑年代不明，十年后双击还能打开。
- **电路求解**：节点法（MNA）线性方程组实时解。关键差异点：**电表默认真实参数**（电流表 0.1 Ω、电压表 3 kΩ，直接用教材练习数据），可一键切"理想"对比——误差可以被学生看见，这是和 wedulab/PhET 拉开距离的地方。
- **文件结构**：`index.html` + `labs/11-1.html … 11-5.html` + `shared/`（一份 CSS/JS）。模块互相隔离。
- **离线**：不需要任何联网能力，file:// 直接跑；另存一份整个文件夹到 U 盘备用。
- **屏幕**：按 1024×768 起步做自适应，主力 1080p；**明确不做手机端**——场景里没有手机。
- **明确不做（现在）**：账号、成绩统计、题库管理、云端同步。常态课只有一个用户，加任何服务端都是在给断网添风险。

## 七、落地路线

- **第 0 步（先别写代码）**：拿 wedulab 的 VoltLab + 教材插图 PPT，按第三节的 11.4 教案上一节真课。要验证的假设只有一个：**"先猜后揭晓"的节奏，在真班里成立吗？** 记两个数：每次预测的举手率、实际耗时。这是整份方案里唯一没有证据的部分。

## 八、对抗审查（红队）

请了一个"见过十个智慧课堂项目死掉"的评审来拆台，11 刀，刀刀要命：

**R0「这东西根本不需要做」**：wedulab、PhET、国家平台资源一大把，自研的边际价值到底是什么？
→ 自研理由只有三个，缺一不做：① 与教材**页码级**对齐（现成平台都是知识点级）；② 大屏 + 翻页笔的课堂形态（现成平台适配鼠标个人电脑）；③ 误差、推理、排查类内容（内外接偏大偏小、黑箱、故障排查）现成平台没有。如果试讲后发现老师更爱用现成的，项目就该停——所以"两周自愿复用"是一票否决指标。

**R1「大屏独唱」**：学生没设备，"交互"只发生在老师和屏幕之间，三个月后就是又一个高级 PPT。
→ 交互定义在课堂，不在屏幕：每模块强制一个全班动作；预测闸门不选选项就不给揭晓；验收时抽查录像数全班动作次数。

**R2「时间黑洞」**：探究再好，常态课要进度；多拖 3 分钟参数，一学期就没人用了。
→ 每模块三档深度 + 内置计时条；台本写明每档对应的教学动作；默认 3 分钟档，8 分钟档留给公开课。

**R3「仿真练不出手感」**：电学是必做实验，卷面还考仪器操作；屏上玩熟了，手接错线。
→ 分工写死：仿真只做"看不见的（电场、漂移、电表偷电流）、危险的（短接爆表）、太贵的（人人一台仪器）"三件事；M6/M11 结尾生成"真表任务卡"（5 个动作清单），课后拿真器材逐个核对，比如灯泡冷电阻 vs 热电阻实测。

**R4「模型边界翻车」**：老师或评委发现动画里的物理不对劲，信任一次性崩塌。
→ 每模块底部常驻一行"模型说明"（假设什么、忽略什么）；电表默认真实参数且可切理想对比；建一份数据校验清单——6.725 mm、0.05 Ω、87.4 Ω、6 Ω/2.5 V 这些教材原值，每个都能在模块里原样复现。

**R5「老师第一次翻车」**：找不到按钮、切错模块，班里一乱，工具判死刑。
→ 单键操作 + 64px 大按钮 + R 键复位；任何状态都能一键回到初始；首次打开弹一张 3 行快捷键卡，之后不再打扰。

**R6「动画偷走注意力」**：粒子越炫记得越少，最后只记得"那个橙色的东西在跑"。
→ 一屏只有一种持续运动元素；特效只在回答"为什么"时出现；结论句揭晓后留在屏上到下一步；禁用音效彩蛋、积分、吉祥物。

**R7「差异分层」**：大屏单通道，快的无聊、慢的掉队，参与的总是那 10 个人。
→ 三层问题备着：全班层（举手）、追问层（点临界生"你猜 C，说说为什么"）、快学生层（揭晓后口头抛一个教材 B 组变式）；老师现场只取一层。

**R8「评价脱节」**：好玩不提分，期末被问"平均分呢？"
→ 出口题全部绑定教材练习原题（本方案已逐条标注页码）；章末前后测用复习与提高 A/B 组；数据就存一个本地 CSV，不建账号系统。

**R9「设备全挂」**：教室断网、一体机死机、老机器卡成幻灯片。
→ 全离线；安全模式应对慢机器；另备打印版（每模块一张 A4：静态图 + 预测题 + 出口题），什么设备都挂了也照常上。

**R10「版权」**：教材原图和 wedulab 界面不能直接扒。
→ 图形全部自绘（Canvas 矢量）；题目少量引用教材练习（校内教学使用，标注出处页码）；学 wedulab 的形态，不抄它的皮。
